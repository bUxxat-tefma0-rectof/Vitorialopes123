# 🐕 Doguinha Store Bot

Bot Telegram para venda de assinaturas premium com PIX automatico.

## Funcionalidades

- Menu interativo com botoes configuraveis
- Catalogo de produtos por categoria
- Compra com verificacao de saldo
- PIX automatico via Mercado Pago
- Sistema de afiliados com comissoes
- Gift Cards
- Historico de compras
- Ranking de vendas/recargas
- Sistema de alertas de reposicao
- Painel administrativo completo
- Tudo editavel pelo admin
